# Paras AI Video Editor

Android video editor with two modes:

## Free
- Manual editing UI
- Video import
- Free Auto Edit (rule-based, not AI)
- 9:16 short-form preset
- Scene/pause analysis plan
- Preset transitions, zooms and filters

## Pro
**₹299/month — 20 AI edits/month**

The Pro service is designed as an online AI processing tier. It can later connect to a secure backend for scene understanding, highlight selection, captions, beat sync and advanced effects. Do not put payment secrets or private API keys in the Android app.

## Build
Open the project in Android Studio and build the debug APK.
